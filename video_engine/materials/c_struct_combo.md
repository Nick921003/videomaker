# C 語言結構體基礎

## 學習目標
理解 struct 與 typedef 的定義方式，能宣告結構體變數並用點運算子存取成員。

## 痛點情境
如果要記錄 100 位學生的姓名與三科成績，用傳統做法要宣告 5 個獨立陣列
（姓名、國文、英文、數學、平均），排序時五個陣列得同步搬動，很容易錯位，
而且函式傳參數要一次傳五個，程式難以維護。資料明明屬於同一個學生，
在程式裡卻是散開的。

## 核心觀念
struct 可以把不同型態的資料打包成單一複合型態。
語法是 typedef struct { 成員列表 } 別名; 三個部分。
成員可以包含 char、int、float 等任意基礎型態，也可以是陣列。
取好別名之後，這個別名就跟 int 一樣可以直接拿來宣告變數。

## 程式碼範例
```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[32];
    int score;
} Student;

int main() {
    Student s1;
    strcpy(s1.name, "Alice");
    s1.score = 95;
    printf("學生: %s, 成績: %d\n", s1.name, s1.score);
    return 0;
}
```

走讀時分四步：定義型態、宣告實體變數、用點運算子存取成員、印出結果。
注意宣告型態的時候還沒有配置記憶體，要宣告變數才有。
姓名是字元陣列不能用等號指定，要用字串複製函式；成績是整數可以直接指定。

## 常見迷思
1. 宣告 struct 只是定義新型態，不會立刻佔用記憶體，要宣告變數才會。
2. 結構體大括號結尾的分號絕對不能漏掉，漏掉會編譯錯誤。
3. 字元陣列成員不能用等號賦值。

## 總結
善用 struct 打包資料，是寫出整潔、模組化程式的關鍵基石。
