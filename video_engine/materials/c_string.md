# C 語言字串基礎

## 學習目標
理解 C 的字串就是「以結束字元收尾的字元陣列」，能正確宣告、複製、量長度，
並知道為什麼不能用等號指定、不能用等號比較。

## 痛點情境
從 Python 轉過來的同學常寫 name = "Alice"，編譯器不一定報錯，但結果一定不對。
因為 C 沒有字串型態，name 只是一塊字元陣列的起點，等號指定的是位址不是內容。
更常見的是宣告 char name[5] 存 "Alice"，五個字母剛好塞滿，
結束字元沒地方放，印出來後面就跟著一串亂碼。
陣列長度要留一格給結束字元，這一格是初學者最常漏掉的。

## 核心觀念
C 的字串沒有專屬型態，它就是一個 char 陣列，結尾多放一個 '\0' 當哨兵。
所有標準函式都靠這個哨兵判斷字串到哪裡結束，沒有它就會一路讀到陣列外面。
所以「容量」和「長度」是兩件事：容量是你宣告的陣列格數，
長度是哨兵前面有幾個字元。存 n 個字的字串，陣列至少要 n 加一格。

## 程式碼範例
```c
#include <stdio.h>
#include <string.h>

int main() {
    char name[32];
    strcpy(name, "Alice");
    printf("%s 共 %d 個字\n", name, (int)strlen(name));
    return 0;
}
```

走讀時分四步：宣告容量 32 格的字元陣列、用字串複製把內容搬進去、
量出結束字元前的長度、印出結果。
第五行宣告的是容量不是長度，這時候陣列裡還是垃圾值。
第六行不能寫成等號，字串內容要靠複製函式一個字元一個字元搬。
第七行量到的是五，不是三十二——量的是內容長度，不是宣告的格數。

## 常見錯誤
用等號比較兩個字串，比到的是兩塊記憶體的位址，永遠不相等，要用字串比較函式。
