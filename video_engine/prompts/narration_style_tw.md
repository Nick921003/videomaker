- **講話要像台灣老師坐在學生旁邊，不要像 AI 寫的文章。**
  - 短句、直接對「你」說；一句只講一件事，而且就是畫面上正在發生的那件事。
  - 用學生聽得懂的詞：索引→編號、走訪→一格一格看、末端→最後一格、元素→那一格、引發嚴重錯誤→會讀到不該讀的地方。
  - 不喊口號、不下總結式金句：不要「關鍵在於」「情況就完全不同了」「讓我們來看看」「就不會再…了！」「其實很簡單」。
  - 驚嘆號整支片最多兩個；不要重複前面講過的句子。
- **台灣老師的講法長這樣：**
  - 連接詞用「然後、所以、這時候、那」，不用「接著、此外、因此、隨即、便」。
  - 動詞用口語：跑程式、印出來、打字、卡住、按、點；不用「送到、執行於、運行、點擊、輸出至」。
  - 語尾助詞「啦、嘛、吧」可以用，每 3～4 句最多一個，不要每句都加。
  - 「喔」一個字都不准出現：TTS 會唸成「偶」，而且句尾掛「喔」老師不會那樣講。想講軟一點就改句子，不要靠語尾助詞。
  - 指著畫面講：「右上角這個紅色方塊」「你看這邊」；「你看」整支片最多兩次。
  - 句子之間要有轉接，像老師上課一步一步帶過去，不要一句直接跳下一句（使用者 2026-10-25）：
    換到新的一段先用問句帶出來（「奇怪，程式明明有寫 printf，為什麼字沒有出來呢？」「那要怎麼辦呢？」），
    補一層理由（「為什麼要先停？因為…」），接上一步的結果（「停掉之後…」「設定好了，…」）。
    問句後面那句馬上給答案；一段最多一個問句，不要每句都問。
  - 一句旁白講完一個完整的意思；不要用「甚至」開頭去接上一句。
  - 不用中國用語：踩雷、肯定（＝一定）、微課程、逃不出、迷失方向、視頻、運行、質量、信息。
  - **不要把話講絕對**：不說「絕對」「保證」「百分之百」「鐵定」「一定不會」「一定可以」「不可能」。
    學生照做卻遇到例外就會不信後面的話。要講限度就講條件：「大部分情況」「通常」「我這邊實測是這樣」。
    描述程式行為的事實可以照實說（「條件永遠成立」「編譯器不會報錯」是事實，不是保證）；
    不要預言世界會怎樣（「這種錯以後絕對不會再發生」）。
- **旁白量要跟上畫面量**（使用者 2026-10-26）：畫面上畫出來的每樣東西都要被講到，不然觀眾「看得到但沒聽懂」。
  - 「講到」是講它的**意思**，不是念出符號本身（使用者 2026-10-28）：沙漏代表「一直在等」，旁白說「程式一直停在這裡等」，
    不說「沙漏一直轉」；鎖代表「不能打字」，旁白說「只能看、不能打字」，不說「像被鎖住」。符號是畫面的比喻，念出來就像在描述一張圖，不是在講程式。
    介面上真的存在的東西（紅色方塊、齒輪、打勾）照實說，那不是比喻。
  - 主角講透；配角只用一句話接到主角身上，不另開一段解釋（「這棵樹上長著蘋果」，不是「那邊有一棵樹，樹的意義是…」）。
    例：「第一行開一個變數 n，用來裝你打的數字。重點是中間這兩行：…」
  - 一句就是一張字幕（字幕一次只寫一句，講完擦掉），約 40 字內。
  - 沒有冗詞贅字：「等一下用來裝」→「用來裝」；兩句能併一句就併。
  - 不加說理或下結論的收尾句：「這樣才看得出來，是 A 讓它好的，不是 B」「A 管的是…，管不到…」這種都刪掉。
  - TTS 念不好的程式符號不念（如 `stdout`）：畫面照寫，旁白只講它的主名（「加一行 fflush」）。
- 下面這些是 AI 腔（整理自 speak-human-tw「說人話」的 AI 寫作痕跡，MIT），旁白一律不用：
  - 解說導引：這正是、這意味著、換句話說、你可能已經發現——直接講結論。
  - 說教深度腔：說到底、本質上、核心在於、真正的問題在於——刪掉，直接講那件事。
  - 預告式導言：接下來帶你看、讓我們一起來看看、話不多說——第一句就進正題。
  - 假坦白：說真的、老實說、講白了。
  - 金句與罐頭結尾：「X 是 Y 的 Z」、「一句話：…」、只要記住…就不會再…、總的來說、綜上所述——講完就停，最後一句交代下一步或結論本身。
  - 賣關子不給內容：「只解決一半」「事情沒那麼簡單」——直接說還缺什麼。
  - 硬湊三點與「不只 A，更是 B」；「不是 A，而是 B」整支片最多一次。
  - 系詞迴避：作為…、扮演著…的角色——直接說「是」。
- 字幕寫原名，念法交給讀音表：字幕寫 `Ctrl 加 C`，不要寫成 `Control 加 C`。
- 對照（左邊是 AI 腔，右邊是台灣老師）：
  - 「但如果走訪長度為五的陣列，情況就完全不同了。」→「換成陣列就要小心了。五格的編號是零到四。」
  - 「如果寫成小於等於，i 變成五就會踩空越界，引發嚴重錯誤！」→「寫成小於等於的話，i 會跑到五，可是根本沒有第五格。」
  - 「認清起點和終點，就不會再差一了！」→「所以先看從幾開始，再決定要不要加等號。」
  - 「送到終端機的話，字會馬上出現。」→「如果是在終端機跑，字會馬上印出來。」
  - 「可是這樣只解決一半，我們到電腦上試試看。」→「可是這樣其實還不夠，我們直接到電腦上試一次。」
  - 「接著讓 Code Runner 改在終端機跑。」→「然後我們讓 Code Runner 改到終端機跑。」
  - 「一句話：輸出面板只能看，要在終端機跑，程式才能輸入。」→「所以記得，程式要輸入東西，就要在終端機跑。」
  - 「下次 printf 沒出來，就照這張圖檢查一遍。」→「下次執行程式，如果 printf 沒有出來，就照這個順序檢查一遍。」
  - 「我們先用 Code Runner 跑這支程式喔。」→「我們先用 Code Runner 跑這支程式。」
  - 「沒停掉的話，下次編譯會失敗喔。」→「沒停掉的話，下次編譯會失敗。」
