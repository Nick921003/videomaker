## 播放與評選

伺服器运行時開啟 http://127.0.0.1:8932/index.html 。切換候選後，點圖片或「播放」看完整動畫；可以暫停、拖曳、重播，並切換成 MP4。首頁靜態圖片只是播放前的效果截圖，動畫從第 0 秒開始。

每支成片與字幕放在 `out/<id>.mp4`、`out/<id>.srt`。影片為 1920×1080、24fps、15 秒、360 幀；字幕已燒入影片，另附 SRT。全片無音訊。頁面的「保留／待調整／淘汰」儲存在此瀏覽器的 localStorage，可匯出 JSON；尚未寫入正式 catalog。

停止伺服器後可在此目錄用現有 Python 啟動：

```sh
python3 -m http.server 8932 --bind 127.0.0.1
```

## 內容與元件來源

`trials.json` 是題材、資料、字幕與節奏的共同來源；`sample.js` 呼叫保存的原始 grammar／kit，額外處理字幕與畫面布局。原始來源固定於 `vendor/sources.json` 的兩個 commit，每檔保存 SHA256，並附 MIT 授權；原始碼未改。

這批由人工編排題材與元件，並未呼叫模型、TTS 或圖像服務，也沒有接上正式聊天製作流程。保留下來後，還需要把適用情境、資料參數和節奏限制接入正式選用機制。

字型使用本機 Noto Sans CJK TC 子集，對原始字型名稱做映射，以保存繁體字並避免播放依賴網路。這會改變原設計的手寫字形；粉筆描繪、板擦、紙片、公式與圖表動畫仍來自原元件。字型來源、雜湊與授權保存在 `vendor/font.json`、`vendor/Noto-CJK-copyright.txt`。

## 重製與驗證

用已有 Playwright 的 Python 執行，不需要安裝新套件：

```sh
/home/pjw92/.local/share/pipx/venvs/webwright/bin/python verify_export.py --export
```

可用 `--ids chalk drafting` 選片，`--url` 指定伺服器。

檢查來源 SHA256、字幕時間／閱讀速度、教材數值，實際啟動 Chromium，比較全新頁面直接跳秒與連續／倒序播放。文字、位置、透明度和字幕狀態要求完全相同。像素比較對瀏覽器 SVG／濾鏡邊緣允許最多 250 像素、最大單色差 24（1080p 的 0.013%），實際差值列在各 report，不能用此容差忽略內容或位置改變。

匯出時每幀量測可見文字的畫面邊界及字幕遮擋；原始 Canvas 卡片的文字經紋理與透視切片追蹤，測量帳本隨 clearRect、reset 和 width/height 重設。字幕 44px。圖表來源註記 26px，卡片入場縮放時的次要文字會短暫小於 28px，完整卡片文字較大。這批保留原始元件的入場行為供評選。

`out/*.report.json` 保存各片實測結果；`*-mp4-*.png` 為從成片抽出的第 0、8、14.9 秒影格。另有比較頁響應尺寸與評選保存檢查。文字驗證不涵蓋所有裝飾／材質的碰撞；元件是否美觀、是否適合完整課程仍由看片評選決定。

鏡頭縮放下的 SVG 尺寸文字使用 geometricPrecision，以避免瀏覽器按照第一次顯示時的縮放比例取整字形。動畫預覽結束停在 14.958 秒的最後實際影格，與 MP4 保留相同末句字幕。

MP4 比較預先完整載入短片為 Blob URL，讓未支援 HTTP Range 的本機靜態伺服器也能跳秒；切换候選时釋放前一個 URL。實測摘要見 VERIFIED.md 與 out/batch.report.json。
