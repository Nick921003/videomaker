- 橘色標目前動作、藍色標條件、綠色標結果；深底使用同色系的較亮版本。元件改呈現用途時保持語意色關係。
- 工程引線按程式的當前邊移動單一標記；當前執行分支互斥，已建立的流程結構保留。成立17秒、返回18.3秒、不成立及離開29秒才首次揭露；箭頭末端等路徑畫完才出現。返回到條件，初始化只執行一次。
- revision 2 的 i／sum 標籤與數值使用獨立 grid row，移除會與數值相交的重複狀態文字；公式先退場舊項、再移動保留符號、最後帶入新值。
- 圖表使用真實走讀次數：主體五次，條件六次。從零基線長出數量；動畫時長不代表運行效能。
- 收尾紙片整面保持平面，以局部折角配合重點揭露，避免大容器翻轉。這是自製折角適配，不是 v4 原 kit 的整面 fold，也未覆蓋原「紙藝折起」候選。
- 概念、工程、量化是呈現用途，不是每個重點隨機換整套皮膚；本片只示範暖色基底，尚無三種整片 preset 的正式選單。
