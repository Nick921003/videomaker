# 參考紀錄

這個專案參考過、拿來用過的外部專案、模型、論文與方法，一律記在這裡。
**規則：參考了新東西就當場加一列**（查了沒用的也記，寫「沒用的原因」），不要等收尾才補。
論文的細節與查核狀態另見 Obsidian `projects/videomaker-相關論文.md`；這裡只記「拿了什麼、接到哪裡」。

欄位：狀態＝採用（程式裡有用到）／參考（看過、拿了想法）／沒用（查過但不適用）。授權寫「待核對」的，對外發布前要回原專案確認。
