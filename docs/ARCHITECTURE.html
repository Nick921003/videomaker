BridgeAI · 影音生產架構提案

王老師微課程引擎

把「一頁一張圖一段音檔」的換頁片，改成語意驅動的動作序列——換教材不用改程式碼，動畫自己跟著跑。

2026-08-24 已取代 generate_v3_master_videos.py 設計參考 OpenMAIC（MIT）

01問題在哪

現在的腳本能出片，但內容、編排、幾何三件事寫在同一支檔案裡。投影片內容是寫死的 dict，動畫時間是手排的順序，座標是常數（code_base_y=310, line_height=42）。換一份教材，三層都要重改一次——所以做不出「任意教材自動出片」。

02三層契約

三份 JSON，各有唯一的作者，誰都不准跨界。這是整個架構唯一要守住的規矩。

03完整管線與工具

八個階段，每段一個工具、一個產物。除了第 2、4 段要花 LLM 額度，其餘全在本機跑。

關鍵改動
繪製器不再只回傳 PNG，而是同時回傳每個元素畫在哪。你的繪製程式本來就知道這件事，現在只是把它寫出來。

04動畫怎麼找到位置

LLM 只會寫 "target": "s2_code:L4-L6"。座標是編譯期查表得到的，換版面、換字級都不用碰 actions.json。

05時間軸怎麼算

動作分兩種：阻塞的佔時間，非阻塞的只是觸發。speech 的長度直接取合成出來的音檔長度，所以講稿一改，後面全部自動位移——沒有任何手寫時間碼。

常數值意義

SPOTLIGHT_HOLD→ next持續到下一個 spotlight 或頁尾

06兩道驗證閘

自動化最怕的是「產出爛東西但流程說成功」。兩個閘門擋在管線裡。

閘一：編排驗證（階段 4 之後）

  • 每個 target 都要能在 lesson.json 解析到，程式碼行號不得越界
  • 每頁 ≥ 3 個動作、≥ 2 段 speech——只有一段就是換頁片，退回重生
  • 所有 hidden 元素都要有對應的 reveal
  • 推近過的鏡頭必須在頁尾前 reset

閘二：語音驗收（階段 5 之後）

AR 模型沒有時長約束，卡住是架構本質不是壞掉。把 rework/v3_stability.py 的 analyse() 接進合成迴圈：長度落在預期區間外、出現 >1.5s 異常靜音、偵測到重複，就重跑，上限三次。

放對位置
驗收要接在合成函式裡，不是接在出片腳本裡。這樣所有呼叫端都自動受保護，不必每支腳本各接一次。

08聲音的三條硬規則

都是實測撞出來的，違反任一條就會產生雜音或誤判。

一　不要讓英文被切成孤立片段

API 的 cut5 會在「、」硬切。「 float ，」 單獨送進 AR 模型實測產生 8.46 秒、峰值 0.02 的近無聲雜訊。25–60 字的講稿一律 cut0 整句送，超長才自己切，且每段保證含中文上下文。

二　靜音偵測不能只用相對門檻

原本用「峰值的 2%」判定靜音。AR 失控產生的雜訊振幅約 0.02，除以該段峰值 0.9 等於 2.2%，剛好高於門檻而被算成「有聲音」，2.7 秒的垃圾整段漏抓。必須同時加絕對門檻（逐框 RMS < 0.015），修齊也要用逐框 RMS 而非單點振幅。

三　講稿不要出現逐字母唸的英文

訓練語料 317 條裡含英文的 30 條全是單字或詞組，沒有任何一條是逐字母唸的。「Bridge AI」實測產生 1.2 秒的氣音——能量在、勉強聽得懂，所以能量檢測與 ASR 回讀都抓不到，只能靠講稿規避。畫面保留英文，講稿改中文說法。

校準值數值怎麼來的
語速6.35 字/秒18 段實測中位數，範圍 4.2–8.3
含停頓語速5.5 字/秒525 字 → 95 秒，供片長預估
絕對靜音門檻RMS 0.015雜訊 0.005、正常語音 0.15

09Repo：Monorepo

已決定走 monorepo——影音引擎與 TTS 訓練同一個 repo。現況是上游 fork：origin 指著 RVC-Boss/GPT-SoVITS，1050 個 commit 裡只有 1 個是自己的，.git 僅 15 MB，歷史不構成負擔。

形狀做法代價
甲（建議） 上游留在 root 不動；自己的東西集中兩處：video_engine/ 與 tts_lab/ 搬的都是自己寫的散檔，絕對路徑照舊可跑；上游修補仍能 pull
乙 真的分成 engine/ 與 tts/，上游整包搬進 tts/ 26 支腳本的硬編路徑要全改；之後每次 merge 上游都會大量衝突

形狀甲的目錄長相：

GPT-SoVITS/            ← repo root（上游程式碼原地不動）
├── GPT_SoVITS/        上游推論與訓練核心
├── video_engine/      影音引擎：schema / prompts / compiler / renderer
├── tts_lab/           自己的訓練資產：auto_train_*.py、rework/、資料集工具
└── output_videos/     產出（不進版控）
