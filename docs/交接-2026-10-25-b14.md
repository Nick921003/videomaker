29 句實際長度對目標長度回歸：

```
最小平方   seconds = 0.9924 × target − 0.890    RMS 0.180
純加法     seconds = target − 0.927             RMS 0.180
純比例     seconds = 0.8146 × target            RMS 0.267
```

**斜率 0.992** → F5 的 `speed` 參數照做得準，**字速是對的**；每句固定少 0.9 秒，與句長無關。
