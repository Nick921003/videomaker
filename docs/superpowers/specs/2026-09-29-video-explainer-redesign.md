# 教學影片場景化改版規格

## 目標

回應實際 A/B 的三個問題：字與動畫疊色後看不清楚、整張固定卡片讓影片像 PPT、同一種「看這裡」語意卻交替用螢光筆和底線。新輸出應像逐步推演的解說畫布；舊輸出保留供相容比較。

## 可觀察的成功條件

1. 既有 `lecture` 片在被強調時，文字像素與原字色保持可辨，不能再被深色逐通道相乘。現況標題從 14.39:1 降到約 2.41:1、條列降到約 2.27:1。新效果至少讓字／局部底色維持 4.5:1，形狀標記相對背景至少 3:1。
2. `spotlight` 和 `laser` 對同一目標共用焦點形狀與顏色，只依語意調整停留時長；`explainer` 的程式碼用左側軌、文字用底線、圖示節點用圈選。標記不覆蓋字形；程式碼可壓低未聚焦行，但目標行保持清楚。
3. 增加可選 `explainer` 視覺模式。第一版依內容語意支援對照、字元模型、程式走讀、錯誤修正四種場景。每種場景全幅構圖、突出正在講的對象，不畫固定 `HEADER_BOX`/`CONTENT_BOX` 卡片；舊 `cards` 模式不變。
4. 新模式仍產生 `base_png`、`full_png` 和可定址 `layout.json` 框，沿用既有 actions、WAV、時間線與 FFmpeg；沒有新座標寫入 lesson/action。hidden 元素只改可見性，不改版位。兩次同輸入 PNG 逐位元組相同，框不溢出畫布。
5. 用既有 `fresh` 的語音和動作做 10–20 秒樣片與全片 A/B，分別在原尺寸、縮小至三分之一與灰階檢查文字和標記。影片檔放 Windows 可直接開啟的位置。樣片內容的「六格／五格」與結尾圖意不符另標為教材資料問題，不由渲染器偷偷編造內容。

## 接口和邊界

- `render_slides.py --visual-style explainer` 為明確選用；預設維持 `cards`。`layout.json`、`timeline.json` 都記錄 visual style，影片渲染器依它選過場與焦點效果。
- `explainer` 使用完整的主題色表，強調色與正文色分工。字型使用已安裝的 Noto；先不新增第三方依賴或呼叫付費教材、動作、語音階段。
- 舊式 `HEADER_BOX`/`CONTENT_BOX` 固定外框不變；新式沒有這兩塊可見卡片，但仍保留安全邊距與實測框。兩種模式共享 1920×1080 輸出。
- 不使用 AGY 或聯絡另一個任務；使用者已要求暫停跨任務溝通。視覺偏好由使用者看片決定。
