# HTML Canvas 教學過程樣片

使用者要求從樣片開始，採後來提供的HTML Canvas seek(t)→Playwright截圖→FFmpeg流程。題材沿用C語法既有printf／換行段落，約20秒，1080p／30fps。舊影片49秒的問題是World!標點拆行、輸出被畫成三個資料格、沒有真正游標換行。

目標：接近第一次A＋C的連續教學過程，而非只修方塊排版。主角為同一程式片段與同一終端機；程式聚焦後，輸出逐步形成Hello, World!，游標接著移到下一行，最後鏡頭留在結果。文字不切詞，線條進場可手繪但穩態不持續抖動。

已有旁白從master.wav的35.74–54.14秒重用；加0.6秒開頭與1秒結尾留白，成20秒。字幕取原最終口語稿與cue，新增LLM／TTS0。不做新F5聲音克隆；這次採用其HTML／渲染流程並保持聲音為控制變因。按示範規格loudnorm I=-16／TP=-1.5，記錄音量處理。

元件是CodeWalkthrough和TerminalOutput的小型原型，由Codex寫HTML／動效，來源分鏡及旁白沿用既有Claude資料；不可稱整支由Claude重新生成。配色讀樣片theme.json；不修改正式pipeline、模型prompt與既有成片。

驗收：seek相同t正反跳轉後PNG相同；所有可見文字／元件在1920×1080及所屬panel內，code與terminal不碰撞；連線端點由當前panel幾何取得；單行輸出原文與標點完整；游標在換行事件前後有正確位置。先抽關鍵帧與3秒片段，再輸出20秒。實際MP4解碼與影格比對、播放器與本機聲音可用。
