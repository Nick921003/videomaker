# 第二步：多格式讀取與共用教材資料

日期：2026-10-08。使用者授權接續八步計畫；第一步必要驗收及AGY回報確認後開始實作。本計畫先保存已盤點的接點。

## 目標

專案自身讀取檔案，保留原始來源、抽取結構、位置與經核對的整理结果。Gemini用統一輸入製作後續教材，不依賴Codex插件、聊天框或外掛快取。保留現有material.md供舊產生器使用，新增版本化JSON契約。

## 已確認現況

- 既有PDF/PPTX抽取使用Poppler/python-pptx；新版上傳5MB，整理30頁／6萬字。
- 現有Pillow、python-pptx可用；沒有python-docx/openpyxl。先用標準庫讀取必要OpenXML，避免新增依賴。
- 舊PPT/DOC/XLS不直接讀取，要求另存為PPTX/DOCX/XLSX；不能把改副檔名當轉檔。
- Gemini視覺接口已有PDF；PPTX含視覺元素用LibreOffice轉PDF。圖片可透過Pillow轉一頁PDF並沿用接口；不把圖片送進文字解析器。
- Library單元ID基於整理後Markdown；相同正文、不同來源必須保留各自來源，不覆蓋第一份原稿。

## 支援範圍與限制

| 類型 | 抽取／來源位置 | 視覺／限制 |
| --- | --- | --- |
| PDF | 原生文字及頁碼 | 掃描／圖表由既有視覺整理；看不清保留疑點 |
| PPTX | 投影片順序、文字、備忘稿、表格 | 既有LibreOffice視覺轉換；不默默忽略視覺 |
| TXT/MD | UTF-8文字、行範圍 | 原文直接保存，不擅改格式；非UTF-8明示錯誤 |
| DOCX | 本文段落、表格、標題順序 | 不宣稱頁碼；圖片／物件需明示與視覺路徑 |
| CSV | 每列／欄、空值、原始字串 | 不自動把數值或首列轉成推論資料 |
| XLSX | 工作表順序、儲存格位置、公式／快取區分 | 不重算公式、不猜日期格式；圖表與圖片明示限制 |
| PNG/JPEG | 原圖、尺寸、單張來源位置 | 限像素與檔案大小，轉視覺PDF；辨識內容需核對 |

本表為實作目標，功能未驗證前網站不標示支援。

## 驗收

不能只確認「有文字」。抽查來源位置、順序、表格空值／數字、原始公式、視覺待核對、正文重用的來源保存。每個格式失敗不產生半完成單元、不自動付費重試。來源／整理／生成用量分開，既有費用未知顯示保留。

本步不改PPTX/SVG/影片產生器；第三步才切入共用資料消费者，第四／第五步再做品質改善及外部動畫候選POC。
