# 影音品質從 70 分提升至 90 分 — 整合執行計畫 (70 to 90 Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 解決影片「講稿生硬」、「動態太像 PPT」、「聲音模型缺字母縮寫」三大核心扣分瓶頸，使教學影片達到 90 分自然生動水準。

**Architecture:** 
1. 提示詞層：重構 `lesson_content.system.md` 與 `slide_actions.system.md`，注入啟發式提問與自然台灣課堂語氣。
2. 視覺動態層：改造 `render_video.py` 與 `compile_timeline.py`，新增開場動態 Hook 與程式碼走讀流動標記，打破靜態 PPT 翻頁感。
3. 聲音模型層：在 `~/projects/GPT-SoVITS` 針對字母縮寫與專有名詞補錄增量語料，微調產出王老師 4.0。

**Tech Stack:** Python 3.10 stdlib, Pillow, FFmpeg, GPT-SoVITS API v2, LLM Prompts.

---

## 為什麼需要這份計畫

2026-08-25 全自動出片管線打通後，使用者評分為「70 分」。
後續雖完成了現場 Demo 前端與版型多樣化（163 個測試全綠），但核心扣分項（那 30 分）並未解決：
1. **講稿生硬（約占 10 分）**：句子碎片化、客觀陳述多、缺乏引導設問與人味。
2. **太像 PPT 不像影片（約占 10 分）**：前兩秒完全靜止、轉場是換頁淡化、指示僅為黃色刷色，大腦本能判定為「幻燈片」。
3. **聲音瑕疵（約占 10 分）**：縮寫（AST、API、BridgeAI）缺乏逐字母語料導致氣音，句尾語調偶有下沉。

## Task 1: 講稿與編排提示詞調優（消除生硬感，立刻提分）

- Modify: `video_engine/prompts/lesson_content.system.md`
- Modify: `video_engine/prompts/slide_actions.system.md`
- Test: `tests/test_script_gate.py`, 驗證生成結果與驗證閘相容

**目標：** 讓 LLM 產出富有啟發性、引人入勝且符合台灣資工系課堂語調的口語講稿。

- [ ] **Step 1: 重構 `lesson_content.system.md` 人設與結構**
  - 引入「資深技術導師」視角，強調「為什麼這件事重要」而非單純列出知識點。
  - 第一頁 `hook` 明確要求以「學生最常踩的崩潰情境／Bug」作為切入點。
  - 走讀頁 `walkthrough` 的 `note` 明確提示講師這段要帶出的核心直覺。
- [ ] **Step 2: 重構 `slide_actions.system.md` 口語句型規範**
  - **打破陳述句單一性**：要求至少在關鍵行引入「設問句」（「大家注意看這裡，如果這樣寫會怎樣？」「關鍵在於...」）。
  - **加入課堂自然連接詞**：允許並引導自然口語助詞與轉折詞（「好，那我們來看一下」「事實上呢」「這裡有個細節大家容易忽略」）。
  - **句長與節奏**：避免過度破碎的斷句，讓語意完整並配合標點自然呼吸。
  - **保留英文大小寫發音規則**：確保現有 `mixed_frontend` 的發音規則不受影響。
- [ ] **Step 3: 用現有教材（如 `c_struct.md` 或 `c_string.md`）生成新講稿進行 A/B 聽感對比**
  - 比對新舊 `actions.json` 的口語流暢度與生動度。

## Task 2: 影片動態感升級（擺脫 PPT 感，打造真正的 Explainer Video）

**Files:**
- Modify: `video_engine/render_video.py`
- Modify: `video_engine/compile_timeline.py`
- Modify: `docs/MOTION_SPEC.md`
- Test: `tests/test_render_video.py`, `tests/test_spotlight.py`

**目標：** 解決「開場前 2 秒靜止像 PPT 截圖」與「轉場換頁感過重」，注入連續鏡頭與活體動態。

- [ ] **Step 1: 實作開場動態 Hook（第 1 秒破除靜態）**
  - 在 p1 第一個影格，標題禁止瞬間靜態出現。
  - 支援標題帶輕微落差滑入（Slide-in with `ease_enter`）或前 1.5 秒微推鏡頭（1.05x -> 1.0x 或 1.0x -> 1.1x），確保影片一播放就有動態感。
- [ ] **Step 2: 程式碼走讀「動態行指示標」（取代生硬矩形螢光筆）**
  - 在目標程式碼行左側加入平滑移動的行號箭頭/亮點標記（Cursor indicator），隨著講稿推進流暢滑至下一行。
  - 配合現有的程式碼卡片壓暗，讓視覺焦點像雷射筆一樣自然跟隨。
- [ ] **Step 3: 示意圖方塊微動態進場**
  - 方塊浮現時加入輕量 Scale (0.95 -> 1.0) 彈性質感，配合 `ease_enter`。
  - 連線與箭頭支援生長動畫（沿路徑畫出），而非整條直接閃現。
- [ ] **Step 4: 運鏡連貫性（Cinematic Transition）**
  - 在章節段落切換時，增加可選的平移（Pan）或縮放過渡，打破純粹的「黑/白畫面淡化換頁」心理模型。

## Task 3: 聲音模型王老師 4.0 增量微調（徹底拔除發音瑕疵）

**目錄：** `~/projects/GPT-SoVITS`

**目標：** 解決字母縮寫（AST、API、Bridge AI）氣音與常用 C 語言關鍵字沉悶問題，產出王老師 4.0 權重。

- [ ] **Step 1: 增量資料集構建（Targeted Letters & Keywords Dataset）**
  - 挑選或錄製 30~50 句高頻縮寫與 C 關鍵字切片：
    - 逐字母語料：`A-S-T`、`A-P-I`、`B-r-i-d-g-e A-I`、`G-P-U`、`C`、`D-K-T`
    - 編程單字：`printf`、`struct`、`typedef`、`return`、`include`、`NULL`
    - 語助詞校對：補齊帶有「齁」的精確標註切片。
- [ ] **Step 2: 執行增量微調 (Incremental Fine-Tuning)**
  - 以王老師 3.0 的權重（GPT e15 / SoVITS e8）為起點。
  - 使用修復後的 `mixed_frontend.py` 跑 4–8 個 Epochs（GPU 約 15 分鐘）。
- [ ] **Step 3: A/B 盲聽評估與權重更新**
  - 跑 `tts_lab/rework/ab_compare.py`，確認字母縮寫不再有氣音、中英切換無爆音。
  - 更新 `GPT_SoVITS/configs/tts_infer.yaml` 指向王老師 4.0。
  - 在 videomaker 端跑 `synth.py` 驗收。
