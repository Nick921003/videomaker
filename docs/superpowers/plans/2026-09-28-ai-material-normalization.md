# 教材抽取後的 AI 整理與圖片理解

日期：2026-09-28。狀態：測試站首版已接通；合成教材真實模型連線通過，品質與成本估算仍待擴大驗收。

## 目標

學生在 BridgeAI 閱讀教材時，可將同一份已發布內容轉為影片、心智圖、簡報等形式。測試站以上傳檔案代替 BridgeAI topic。抽取後的文字可能順序錯亂、換行破碎或含 OCR 雜訊，因此先建立一次可重用的「整理版教材」，再供各形式生成。

## 流程與責任

1. **上傳與原始抽取（免費、確定性）：** 檢查檔案白名單、大小及版本雜湊。對 Markdown／TXT 保留文字，PPTX 保留頁序、文字及備忘稿，PDF 保留每頁文字；原始檔與抽取稿仍留存。
2. **成本預覽與確認：** 顯示將使用 Gemini 3.8 Flash 整理內容與讀取教材圖片。使用者確認前不呼叫付費模型；失敗時維持原稿可核對，不標成已整理。
3. **AI 整理（共用一次）：** 修復閱讀順序、雜訊及段落，提取概念／術語、圖表資訊、疑點與頁碼。模型只能根據原稿或圖像修正，不能補寫沒有依據的教學事實。整理稿通過結構與大小驗證後建立新 revision，保留前一版。
4. **選擇呈現形式：** 影片、心智圖及簡報讀同一整理稿。Opus 5.5 負責教學內容骨架及圖／簡報內容，Gemini 3.8 Flash 負責影片逐頁動作及前述教材整理。規則式計畫仍免費。
5. **BridgeAI 接軌：** 來源索引將來由 `upload:file` 改為 `bridgeai:topic`，並含 topic revision；整理稿與產物都綁定該 revision。教師更新教材時，舊產物標示過期。

## 圖片與掃描頁

- PDF 原生文字以抽取結果為主；文字很少或有圖表、流程圖的頁面交給支援 PDF／圖片的視覺模型。PPTX 圖片及圖表需按投影片頁碼附上；文字截圖採 OCR 與視覺理解，示意圖記錄物件及關係，數據圖保留軸、單位、數值與不確定性。
- 原圖是證據，模型描述是輔助資料。模糊、被裁切、低解析度、複雜數據圖或模型無法確定的部分須標記待核對；不據此自動生成數值結論。
- 控制送出頁數及圖片數量，避免大檔成本失控；在 UI 說明哪些頁面會使用視覺模型。下一步優先只分析有教學資訊的圖片／圖表，若使用者另選全頁模式則調整。

## 本輪驗收

- 模型預設 ID 已切換，教學骨架／簡報／心智圖用 Opus 5.5，影片動作用 Flash 3.8；教材整理固定用 Flash 3.8（可由 `STUDIO_INGEST_MODEL` 覆蓋）。
- PDF 有文字層時可按頁抽取；無文字層時能辨識為需要視覺處理，不能默默生成空稿。
- AI 整理有獨立的確認入口、明確狀態、來源版本與可檢查原文；失敗不覆蓋原稿。
- 已用公開合成教材與 mock 模型測試來源版本、PDF 頁碼、PPTX 圖像轉 PDF、CSRF 與上傳 API。Python 271 項（1 略過）及前端 19 項通過。另以公開合成文字、只有圖片的 PDF 及 8901 HTTP 工作流實測 Gemini 3.8 Flash，並以極短合成 JSON 實測 Opus 5.5。未對私有教材呼叫外部模型；真實教材品質、數據圖忠實度與費用估算仍待驗收。

## 目前限制與下一步

- PDF 視覺整理會將整份最多 30 頁、5 MB 的 PDF 交給 Gemini；PPTX 含圖片、圖表或表格時先以 LibreOffice 轉 PDF。模型指令只描述教學相關圖片，但尚未做到逐張圖片的確定性篩選。這點及費用估算需依使用者對範圍問題的回覆調整。
- 單次整理上限 30 頁或 6 萬字；更長教材需要分批處理與合併驗證。
- UI 顯示原始抽取摘要及整理稿摘要；完整原文仍保存在來源檔，尚未提供完整逐頁比較介面。
- 目前只靠逐頁原文摘錄驗證部分來源，不能保證 AI 整理全文逐句正確。需增加逐項引用／差異審核，並以公開合成的 PDF、掃描頁及數據圖做真實模型驗收。
- 本輪修正版在隔離的 8902 服務預覽；舊 8901 程序目前已停止，記憶體中的上傳狀態無法沿用。

`max_tokens` 包含 Opus 5.5 的思考與可見回應。呼叫端只能要求更低值，不能突破階段上限；收到 `max_tokens` 截斷就報錯，不採用不完整 JSON。影片教材結構化與逐頁動作各最多重試三次，因此工作總量仍可能高於單次上限；若真實教材測試常觸頂，優先縮小任務或分批處理，再根據使用量調整。參考 [Anthropic effort 文件](https://platform.claude.com/docs/en/build-with-claude/effort) 與 [Opus 5.5 遷移指南](https://platform.claude.com/docs/en/models/opus-5-5/migration-guide)。
