# 黑板風格套件（chalk kit）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把岚叔 v8-chalkboard 複製成我們自己的 `video_engine/explainer/chalk/`，範本就是 printf b13 的樣子，一支 `chalk_film.py` 從講稿跑到打包，並用 printf 重開做逐位元組驗收。

**Architecture:** 三層分開——`kit/`（風格，與岚叔目前逐位元組相同，以後可以自己改）、`starter/`（b13 的版面與工具，beats.js 用佔位版）、`tools/`＋`chalk_film.py`（流程）。驗收不覆蓋現有 b13 專案：建到新目錄再跟 b13 比，比不過就是範本漏東西。

**Tech Stack:** Python 3（stdlib＋numpy，不新增依賴）、bash、node／npx `hyperframes@0.8.81`、F5-TTS（`~/.venvs/f5tts/bin/python`）。測試走 `.venv/bin/python -m unittest`。

## Global Constraints

- `_vendor/` 只當參考庫，**不改、不再 sync**。
- 保留原作者 MIT `LICENSE`。
- VS Code 電腦畫面的畫法（printf `beats.js` 第 321–976 行）**這次不抽**成共用元件；範本保留電腦畫面段的版面與鏡頭。
- 縮排 Tab（4 格），註解用中文、只寫「為什麼」。
- 不新增第三方依賴（現有：Pillow、fontTools、python-pptx、numpy、soundfile、torch）。
- 不跑付費階段、不跑 GPU TTS：`narrate` 以 `F5Narrator._infer` 擋住，快取沒中就停下回報。
- 本計畫**不渲染影片**。要出片時照記憶 `render-off-local`：優先 Colab，本機一律 `nice 19`＋`ionice idle`。
- 停頓常數配對（`f5_story.py` ↔ `starter/index.html`）：`ERASE_GAP 1.8` ↔ `ERASE_AT`／`ERASE_DUR 1.5`、`TRAVEL_GAP 1.2` ↔ `LEAVE`／`PAN`／`SETTLE`、`SCREEN_GAP 2.5` ↔ 進出螢幕鏡頭。

## 與設計書的差異（請先看這三條）

設計書 `docs/superpowers/specs/2026-10-25-chalk-kit-design.md` 列了七支 tools，本計畫只複製五支，理由如下。要照原樣全複製的話，說一聲。

1. **不複製 `new_film.sh`**：`chalk_film.py new` 就是它，兩份會各走各的（DRY）。
2. **不複製 `render.sh`**：它第 12 行 `FINALIZE="$ROOT/../scripts/finalize_delivery.sh"` 指到岚叔 repo 外面；搬進來就是一條死路徑，或者要連 9.5K 的 `finalize_delivery.sh` 一起搬。渲染本來就走 `pack` → Colab（記憶 `render-off-local`），本機只出審片版，`chalk_film.py render` 直接呼叫 `npx hyperframes render` 就夠。
3. **不複製 `srt.py`**：它只被 `render.sh` 呼叫，搬進來是孤兒。要字幕時再從 `_vendor` 取。

另外：`f5_story.py` **留在 `video_engine/explainer/`**，不搬進 `chalk/`。它是 F5 接岚叔 story 格式的橋，以後白板（花叔）也要用；`chalk_film.py` 用相對路徑找它，可用環境變數 `F5_STORY` 覆蓋，所以 `chalk/` 不綁死它。只在它裡面補上停頓常數的配對註解（Task 6）。

## 已查核的事實（寫計畫時實際驗過，別重查）

- b13 專案的 `lib/kit/` 與 `_vendor` 的 `kits/v8-chalkboard`（排除 starter）**逐位元組相同**；`lib/core.js`、`lib/sfxlib.py` 的 md5 也與 `_vendor/explainer/core/` 相同（vendor commit `762d3ee`）。所以直接複製 vendor 就能做出逐位元組相同的 build。
- b13 的 `index.html` **沒有任何** printf／scanf／Code Runner／fflush／齒輪／run in terminal 字樣——版面是通用的，可以整份當範本。
- `index.html` 有 `/* fonts:begin */ … /* fonts:end */` 標記，`fonts.py` 只替換這段；b13 那份裡面已經有上一支片產生的 `@font-face`，複製成範本時要清空。
- 音效是決定性的：`core/sfxlib.py` 固定 seed `20261005`，`tools/sfx.sh` 先用 `node lib/kit/chalklog.mjs` 把頁面事件讀回來再產 `sfx.wav`。所以 `sfx.wav`、`chalk-log.json` 都可以進逐位元組閘。
- `meta.json` 帶 `createdAt` 時間戳，**不能**進逐位元組閘。
- `video_engine/out/` 在 `.gitignore` 第 2 行——**b13 不在版控裡，弄壞了救不回來**。所以 Task 1 第一步先存基準 md5，驗收一律建到新目錄。
- `assets/img/` 的 **15 張**截圖（含 `_full` 原圖）是手工素材、不是流程產物，但**要進閘**：漏抄一張或抄到舊版，畫面就錯而沒人知道。
- 本機 Python 是 **3.10.20**，`Path.glob("lib/kit/**")` **只回目錄**（`**` 連檔案是 3.13 才改的行為）。要列檔案得寫 `lib/kit/**/*` 或 `rglob`。第一版的閘就是踩這個，45 個檔只比到 17 個而測試全綠。
- `tools/sfx.sh:11` 讀的是 **`PYTHON`** 環境變數（`PY="${PYTHON:-python3}"`），不是命令列參數；系統 `python3`（3.12.3）**沒有 numpy**。
- b13 自己的 `qa/composition.json` 就是 `"ok": false`（`recap end` 的 `diff 0.0`），而 vendor `qa.py` 結尾 `return 0 if report["ok"] else 1` → **`qa` 不能當硬閘，否則永遠紅**。
- b13 的 `tools/anchor_check.py:24` 註解裡有 `Code Runner`（在說明 runtime 怎麼去空白比對），是正當註解，不是殘留的題材字串。
- vendor `tools/render.sh:12` 的 `FINALIZE="$ROOT/../scripts/finalize_delivery.sh"` 指到 `explainer/` 外面，搬進來是死路徑（所以不複製它）。
- `tar --exclude=… -czf out.tgz -C <parent> <name>` 這個寫法是對的（GNU tar 1.35 實測，`renders`／`qa`／`node_modules` 都排掉了）。

```python
#!/usr/bin/env python3
"""黑板片的一條流程：new → narrate → build → check／report → pack，accept 做逐位元組驗收。

用法見 README.md。
"""
import hashlib
import os
import re
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
HF = os.environ.get("HYPERFRAMES", "hyperframes@0.8.81")

FONTS_BLOCK = re.compile(r"/\* fonts:begin \*/.*?/\* fonts:end \*/", re.S)

# 渲染產物與套件管理的東西不屬於片本身
EXCLUDE_DIRS = ("renders", "qa", "node_modules", ".git", "outputs")
# createdAt 每次都不同
EXACT_SKIP = ("meta.json",)
# fonts.py 的子集產物：位元組跟 fontTools 版本與下載結果有關，只比「有沒有這個字型」
SOFT_PREFIX = ("assets/fonts/",)
EXPECT_SKIP = 1
EXPECT_SOFT = 6


def normalize_index(text: str) -> str:
	"""把 fonts.py 產生的 @font-face 區塊換成固定字樣，其餘逐字保留。"""
	out, n = FONTS_BLOCK.subn("/* fonts:begin */FONTS/* fonts:end */", text, count=1)
	if n != 1:
		# 標記不見了不能當成「沒字型要比」——那是閘自己壞掉
		raise SystemExit("index.html 找不到 /* fonts:begin */ … /* fonts:end */ 標記")
	return out


def raw_md5(path: Path) -> str:
	return hashlib.md5(Path(path).read_bytes()).hexdigest()


def film_files(root: Path) -> list[str]:
	"""片裡所有該被看顧的檔（相對路徑，排序）。清單走檔案系統，不靠白名單。"""
	root = Path(root)
	if not root.is_dir():
		raise SystemExit(f"不是目錄：{root}")
	out = []
	for path in root.rglob("*"):
		if not path.is_file():
			continue
		rel = path.relative_to(root)
		if rel.parts[0] in EXCLUDE_DIRS:
			continue
		out.append(rel.as_posix())
	return sorted(out)


def partition(rels: list[str]):
	hard, soft, skip = [], [], []
	for rel in rels:
		if rel in EXACT_SKIP:
			skip.append(rel)
		elif rel.startswith(SOFT_PREFIX):
			soft.append(rel)
		else:
			hard.append(rel)
	return hard, soft, skip


def digest(root: Path, rel: str) -> str:
	data = (Path(root) / rel).read_bytes()
	if rel == "index.html":
		data = normalize_index(data.decode("utf-8")).encode("utf-8")
	return hashlib.md5(data).hexdigest()


def compare(new: Path, base: Path, expect_total: int | None = None) -> list[str]:
	"""回傳差異描述；空清單＝逐位元組相同。閘自己壞掉時 raise，不回空清單。"""
	rels = sorted(set(film_files(new)) | set(film_files(base)))
	hard, soft, skip = partition(rels)
	if not rels:
		raise SystemExit(f"閘沒有東西可比：{new} 與 {base} 都是空的")
	if not hard:
		raise SystemExit("閘沒有任何硬比的檔——例外清單把全部吃掉了")
	if len(skip) != EXPECT_SKIP or len(soft) != EXPECT_SOFT:
		raise SystemExit(f"例外筆數不對：跳過 {len(skip)}（預期 {EXPECT_SKIP}）、"
			f"字型 {len(soft)}（預期 {EXPECT_SOFT}）——fonts.py 沒跑完就會這樣")
	if expect_total is not None and len(rels) != expect_total:
		raise SystemExit(f"閘的覆蓋數不對：{len(rels)} ≠ 預期 {expect_total}")
	out = []
	for rel in hard:
		a, b = Path(new) / rel, Path(base) / rel
		if not a.is_file():
			out.append(f"新專案少了 {rel}")
		elif not b.is_file():
			out.append(f"新專案多了 {rel}")
		elif digest(new, rel) != digest(base, rel):
			out.append(f"{rel} 不同（{digest(new, rel)[:8]} ≠ {digest(base, rel)[:8]}）")
	for rel in soft:
		if not (Path(new) / rel).is_file():
			out.append(f"新專案少了字型 {rel}")
		elif not (Path(base) / rel).is_file():
			out.append(f"新專案多了字型 {rel}")
	return out


def manifest_names(path: Path) -> list[str]:
	"""讀 md5sum 格式的清單（`<md5>  <相對路徑>`），回傳排序後的路徑。"""
	rels = []
	for line in Path(path).read_text(encoding="utf-8").splitlines():
		if not line.strip():
			continue
		parts = line.split("  ", 1)
		if len(parts) != 2:
			raise SystemExit(f"清單格式不對：{line!r}")
		rels.append(parts[1])
	return sorted(rels)


def verify_manifest(base: Path, path: Path) -> list[str]:
	"""基準片有沒有被動過：逐行比原始 md5（不正規化）。回傳差異描述。"""
	want = {}
	for line in Path(path).read_text(encoding="utf-8").splitlines():
		if line.strip():
			md5, rel = line.split("  ", 1)
			want[rel] = md5
	out = []
	have = set(film_files(base))
	for rel, md5 in sorted(want.items()):
		if rel not in have:
			out.append(f"基準片少了 {rel}")
		elif raw_md5(Path(base) / rel) != md5:
			out.append(f"基準片的 {rel} 被改過")
	for rel in sorted(have - set(want)):
		out.append(f"基準片多了 {rel}")
	return out


def set_package_name(text: str, name: str) -> str:
	"""只換 name 欄位的值，格式逐字保留——package.json 要進逐位元組閘。"""
	out, n = re.subn(r'("name"\s*:\s*)"[^"]*"', lambda m: m.group(1) + f'"{name}"', text, count=1)
	if n != 1:
		raise SystemExit("package.json 找不到 name 欄位")
	return out


def build_steps(project: Path, story: Path, python: str | None = None, sfx_python: str | None = None):
	"""四元組 (標籤, argv, cwd, env)。sfx.sh 讀的是 PYTHON 環境變數，不是參數。"""
	python = python or sys.executable
	sfx_python = sfx_python or python
	tools = HERE / "tools"
	return [
		("sync", ["bash", str(tools / "sync.sh"), str(project), str(story)], None, None),
		("stamp", [python, str(tools / "stamp.py"), str(project)], None, None),
		("fonts", [python, str(tools / "fonts.py"), str(project)], None, None),
		("sfx", ["bash", "tools/sfx.sh"], Path(project), {"PYTHON": sfx_python}),
	]


def check_steps(project: Path, python: str | None = None):
	"""硬閘：錨點解不到、hyperframes 有 error，就該停。"""
	python = python or sys.executable
	return [
		("anchor", [python, "tools/anchor_check.py"], Path(project), None),
		("hyperframes", ["npx", "--yes", HF, "check"], Path(project), None),
	]


def report_steps(project: Path, python: str | None = None):
	"""只回報：qa.py 對 recap 結尾的靜止一定回 1（b13 本來就是），不能當閘。"""
	python = python or sys.executable
	return [("qa", [python, str(HERE / "tools/qa.py"), str(project)], None, None)]

def run(label: str, argv: list[str], cwd: Path | None, env: dict | None = None) -> int:
	import subprocess
	print(f"\n── {label}: {' '.join(argv)}", flush=True)
	e = {**os.environ, **env} if env else None
	return subprocess.run(argv, cwd=str(cwd) if cwd else None, env=e).returncode


def run_all(steps, hard: bool = True) -> list[str]:
	"""hard=True：一失敗就停。hard=False：跑完全部，回傳失敗的標籤。"""
	bad = []
	for label, argv, cwd, env in steps:
		rc = run(label, argv, cwd, env)
		if rc != 0:
			if hard:
				raise SystemExit(f"{label} 失敗（exit {rc}）")
			print(f"   ⚠ {label} 回 {rc}（只回報，不當閘）")
			bad.append(label)
	return bad


def preflight(sfx_python: str) -> None:
	"""建任何東西之前先驗環境——缺一塊就不要留下半成品專案（照 vendor new_film.sh）。"""
	import shutil as sh
	import subprocess
	missing = [t for t in ("node", "npx", "ffmpeg", "rsync") if sh.which(t) is None]
	if missing:
		raise SystemExit("缺工具：" + "、".join(missing))
	if subprocess.run([sfx_python, "-c", "import numpy"], capture_output=True).returncode != 0:
		raise SystemExit(f"{sfx_python} 沒有 numpy（音效需要）——用 --sfx-python 指一個有的")
	# chalklog.mjs 要 puppeteer 的 chrome-headless-shell，先讓 npx 準備好
	subprocess.run(["npx", "--yes", HF, "browser", "ensure"], capture_output=True)
	print("pre-flight ok：node／npx／ffmpeg／rsync 都在，音效 Python 有 numpy")

	import datetime
	import shutil
	import subprocess
	if (project / "index.html").exists() and not force:
		raise SystemExit(f"已經有片了：{project}（--force 才覆蓋範本檔）")
	if not (story / "script.md").is_file():
		raise SystemExit(f"{story} 沒有 script.md")
	preflight(sfx_python)
	project.mkdir(parents=True, exist_ok=True)

	name = name or project.resolve().name
	pkg = project / "package.json"
	pkg.write_text(set_package_name(pkg.read_text(encoding="utf-8"), name), encoding="utf-8")

def cmd_accept(project: Path, base: Path, manifest: Path | None) -> None:
	expect = None
	if manifest is not None:
		names = manifest_names(manifest)
		drift = verify_manifest(base, manifest)
		if drift:
			print(f"基準片與清單不符（{len(drift)} 項）——基準被動過了，先查清楚再驗收：")
			for m in drift:
				print("  " + m)
			raise SystemExit(1)
		expect = len(names)
		print(f"基準片與清單一致：{expect} 個檔")
	bad = compare(project, base, expect_total=expect)
	hard, soft, skip = partition(film_files(base))
	head = f"逐位元組閘：{len(hard) + len(soft) + len(skip)} 個檔（硬比 {len(hard)}、字型只比存在 {len(soft)}、跳過 {len(skip)}）"
	if bad:
		print(f"{head}，{len(bad)} 個不同")
		for m in bad:
			print("  " + m)
		raise SystemExit(1)
	print(f"{head}全部相同")


def main() -> int:
	import argparse
	ap = argparse.ArgumentParser(description="黑板片的一條流程")
	sub = ap.add_subparsers(dest="cmd", required=True)
	DEFAULT_SFX = str(Path.home() / ".venvs/f5tts/bin/python")
	q = sub.add_parser("new"); q.add_argument("story"); q.add_argument("project")
	q.add_argument("--name"); q.add_argument("--force", action="store_true")
	q.add_argument("--sfx-python", default=DEFAULT_SFX)
	q = sub.add_parser("narrate"); q.add_argument("story")
	q = sub.add_parser("build"); q.add_argument("project"); q.add_argument("story")
	q.add_argument("--sfx-python", default=DEFAULT_SFX)
	q = sub.add_parser("check"); q.add_argument("project")
	q = sub.add_parser("report"); q.add_argument("project")
	q = sub.add_parser("pack"); q.add_argument("project"); q.add_argument("name")
	q = sub.add_parser("accept"); q.add_argument("project"); q.add_argument("baseline")
	q.add_argument("--manifest")
	a = ap.parse_args()
	if a.cmd == "new":
		cmd_new(Path(a.story), Path(a.project), a.name, a.force, a.sfx_python)
	elif a.cmd == "narrate":
		cmd_narrate(Path(a.story))
	elif a.cmd == "build":
		cmd_build(Path(a.project), Path(a.story), a.sfx_python)
	elif a.cmd == "check":
		run_all(check_steps(Path(a.project), sys.executable))
	elif a.cmd == "report":
		run_all(report_steps(Path(a.project), sys.executable), hard=False)
	elif a.cmd == "pack":
		cmd_pack(Path(a.project), a.name)
	elif a.cmd == "accept":
		cmd_accept(Path(a.project), Path(a.baseline), Path(a.manifest) if a.manifest else None)
	return 0


if __name__ == "__main__":
	sys.exit(main())

#!/usr/bin/env python3
"""在 Colab 渲染黑板片：md5 對上才解壓，渲染脫離 notebook 的 session，最後縮一份審片版。

Colab 上一格（不需要裝任何套件，只要 node 與 ffmpeg）：
  import sys; sys.path.insert(0, "/content/chalk")
  from colab_render import main
  main("/content/drive/MyDrive/videomaker_render/x.tgz", "<md5>", "/content/x")

為什麼要這樣寫（記憶 render-off-local）：
- md5 不對就停：Google 雲端同步到一半的 tgz 解出來是壞的，而且壞得很安靜。
- start_new_session=True：notebook 的 cell 一斷線，子程序會跟著被收走。
- ffmpeg 加 -nostdin：notebook 裡沒有 stdin，不加會卡住不動。
- 預設保留全解析度 master：刪掉的話要出成品得整支重渲（vendor render.sh 只在 DRAFT 分支刪）。
"""
import argparse
import hashlib
import os
import subprocess
import sys
import tarfile
from pathlib import Path

HF = os.environ.get("HYPERFRAMES", "hyperframes@0.8.81")


def main(tgz: str, want_md5: str, out: str, keep_master: bool = True) -> int:
	print("cpu:", os.cpu_count())
	tgz_path = Path(tgz)
	got = hashlib.md5(tgz_path.read_bytes()).hexdigest()
	if got != want_md5:
		raise SystemExit(f"md5 不對：{got} ≠ {want_md5}（雲端還在同步就會這樣，等一下再跑）")
	dest = Path(out)
	dest.mkdir(parents=True, exist_ok=True)
	with tarfile.open(tgz_path) as tar:
		try:
			tar.extractall(dest, filter="data")   # 3.12 起的預設方向，3.14 會強制
		except TypeError:
			tar.extractall(dest)
	project = next(p for p in dest.iterdir() if (p / "index.html").is_file())
	full = project / "renders/draft-full.mp4"
	full.parent.mkdir(parents=True, exist_ok=True)
	p = subprocess.Popen(["npx", "--yes", HF, "render", "--quality", "draft", "--fps", "30",
		"-o", "renders/draft-full.mp4"], cwd=str(project), start_new_session=True)
	if p.wait() != 0:
		raise SystemExit(f"render 失敗（exit {p.returncode}）")
	review = project / "renders/draft.mp4"
	subprocess.run(["ffmpeg", "-nostdin", "-y", "-loglevel", "error", "-i", str(full),
		"-vf", "scale=1280:-2", "-c:v", "libx264", "-crf", "30", "-preset", "veryfast",
		"-c:a", "aac", "-b:a", "96k", "-movflags", "+faststart", str(review)], check=True)
	if not keep_master:
		full.unlink()
	print("審片版：", review, review.stat().st_size // 1024, "KB")
	print("md5", hashlib.md5(review.read_bytes()).hexdigest())
	if keep_master:
		print("master 留著：", full)
	return 0


if __name__ == "__main__":
	ap = argparse.ArgumentParser(description="在 Colab 渲染黑板片")
	ap.add_argument("tgz")
	ap.add_argument("md5")
	ap.add_argument("out")
	ap.add_argument("--no-keep-master", action="store_true", help="渲完刪掉全解析度檔（預設保留）")
	a = ap.parse_args()
	sys.exit(main(a.tgz, a.md5, a.out, keep_master=not a.no_keep_master))
```
