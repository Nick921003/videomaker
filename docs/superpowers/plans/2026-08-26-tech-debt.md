上一輪的最終審查列了 11 項技術債，交給 AGY 以「一個操作者、一台筆電、現場 Demo」的定位重新裁決，結論是**拒絕 9 項、只做 2 項**。我逐條查證後採納它的裁決，但推翻它三個論斷中的兩個：

| AGY 的說法 | 查證結果 |
| :--- | :--- |
| 「SSE 的 `try` 只包 `wfile.write`」 | **錯**。`try` 包住整個內層區塊含 `while` 迴圈。但結論（不修）仍成立——那區塊裡只有 `_push` 會丟 `OSError` |

| 「Ctrl+C 會留下孤兒子行程」 | **對，而且不在原本的 11 項清單裡** |

被拒絕的 9 項理由一致：**改動代價落在一個目前 48 個測試全綠、端到端實證過的系統上，而收益說不出具體會避免哪個失敗。**「比較乾淨」不是收益。特別記錄兩項推翻：

### Task 1: 子行程的生命週期

**Files:**
- Modify: `serve.py`
- Test: `tests/test_serve_children.py`（新增）

**Interfaces:**
- Produces: `spawn(args) -> subprocess.Popen`，開子行程並登記到存活集合
- Produces: `reap(p) -> None`，確保子行程死透並解除登記（可重複呼叫）
- Produces: `kill_children() -> int`，收掉所有還活著的子行程，回傳收掉幾個
- Produces: `shutdown(srv) -> int`，收工：先收子行程再關 socket，回傳收掉幾個

**兩個問題其實是同一個：子行程活得比擁有它的東西久。**

1. `real_runner` 的事件迴圈一收到 `stage_fail` 就 return，generator 被丟在 `yield` 上，`p.wait()` 永遠不會執行。今天 `run.py` 遇到子階段失敗會自己 `SystemExit`，所以子行程本來就在死——但如果迴圈是因為**例外**中斷，`run.py` 會在背景把整條管線跑完，繼續寫 `examples/` 與 `out/`，而 job 已經是 `failed`、服務會放行下一個 job。「同時只跑一個」這個不變量守在 Job 物件上，**沒有守在 OS 行程上**。
2. `serve_forever()` 沒有任何收尾。所有執行緒是 `daemon=True` 會跟著死，但 `Popen` 是獨立的 OS 行程——按下 Ctrl+C 之後它繼續跑管線、繼續打 TTS、繼續寫檔案，而操作者以為已經停了。

import subprocess
import sys
import time
import unittest

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, ROOT)

import serve


def _sleeper():
	"""開一個會活很久的子行程，用來驗證我們真的收得掉它"""
	return serve.spawn([sys.executable, "-c", "import time; time.sleep(30)"])


class TestChildLifecycle(unittest.TestCase):
	def tearDown(self):
		serve.kill_children()

	def test_spawn_會登記到存活集合(self):
		p = _sleeper()
		self.addCleanup(serve.reap, p)
		self.assertIn(p, serve.live_children())

	def test_reap_收掉子行程且可以重複呼叫(self):
		p = _sleeper()
		serve.reap(p)
		self.assertIsNotNone(p.poll(), "子行程還活著")
		self.assertNotIn(p, serve.live_children())
		serve.reap(p)      # 第二次不可以炸

	def test_kill_children_收掉全部(self):
		a, b = _sleeper(), _sleeper()
		self.assertEqual(serve.kill_children(), 2)
		self.assertIsNotNone(a.poll())
		self.assertIsNotNone(b.poll())
		self.assertEqual(serve.live_children(), set())

	def test_generator_被丟掉時子行程要跟著死(self):
		# real_runner 的事件迴圈一收到 stage_fail 就 return，generator 被丟在
		# yield 上。沒有 finally 的話子行程會在背景把整條管線跑完，
		# 而 job 已經標成 failed、服務會放行下一個 job
		holder = {}

		def gen():
			p = _sleeper()
			holder["p"] = p
			try:
				yield 1
				yield 2
			finally:
				serve.reap(p)

		g = gen()
		next(g)
		self.assertIsNone(holder["p"].poll(), "測試前提：子行程應該還活著")
		g.close()          # 等同 generator 被丟棄
		self.assertIsNotNone(holder["p"].poll(), "generator 收掉了，子行程卻還活著")


if __name__ == "__main__":
	unittest.main()

在 `serve.py` 的 `real_runner` **之前**加入：

```python
_children = set()
_children_lock = threading.Lock()


def spawn(args):
	"""開子行程並登記。登記是為了 Ctrl+C 時收得掉——
	執行緒是 daemon 會跟著死，但 Popen 是獨立的 OS 行程不會"""
	p = subprocess.Popen(args, stdout=subprocess.DEVNULL,
		stderr=subprocess.PIPE, text=True, bufsize=1)
	with _children_lock:
		_children.add(p)
	return p


def reap(p):
	"""確保子行程死透並解除登記。可以重複呼叫"""
	if p.poll() is None:
		p.kill()
		p.wait()
	with _children_lock:
		_children.discard(p)


def kill_children():
	"""收掉所有還活著的子行程，回傳收掉幾個"""
	with _children_lock:
		alive = list(_children)
	for p in alive:
		reap(p)
	return len(alive)


def live_children():
	with _children_lock:
		return set(_children)
```

#!/usr/bin/env python3
"""從本機真的跑過的產出，抽出回歸測試需要的兩份 JSON 並洗掉絕對路徑。

用法：.venv/bin/python tests/fixtures/regression/make_fixtures.py

只有在 compile_timeline.py 的輸入契約改變時才需要重跑。
洗路徑是必要的：原檔裡的 png / wav 是絕對路徑，含產生者的家目錄。
compile_timeline 只把這些字串抄進時間軸、從不開啟，所以換成佔位字串
不影響任何行為。
"""
import json
import os

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.dirname(os.path.dirname(os.path.dirname(HERE)))
OUT = os.path.join(ROOT, "video_engine", "out")
PLACEHOLDER = "FIXTURE"


def scrub(obj, real_prefix):
	"""把絕對路徑換成佔位字串，其餘原封不動"""
	if isinstance(obj, dict):
		return {k: scrub(v, real_prefix) for k, v in obj.items()}
	if isinstance(obj, list):
		return [scrub(v, real_prefix) for v in obj]
	if isinstance(obj, str) and obj.startswith(real_prefix):
		return PLACEHOLDER + obj[len(real_prefix):]
	return obj


def main():
	for lesson_id in ("c_struct", "c_string"):
		src = os.path.join(OUT, lesson_id)
		dst = os.path.join(HERE, lesson_id)
		os.makedirs(dst, exist_ok=True)
		for name in ("layout.json", "durations.json"):
			with open(os.path.join(src, name), encoding="utf-8") as f:
				data = json.load(f)
			with open(os.path.join(dst, name), "w", encoding="utf-8") as f:
				json.dump(scrub(data, ROOT), f, ensure_ascii=False, indent="\t")
		print(f"寫好 {dst}")


if __name__ == "__main__":
	main()
```

- [ ] **Step 1: 更新 SSE 載荷契約**

spec 的「HTTP 介面契約」節寫 SSE 每則是 `{stage, status, pct, msg}`。實際送的是兩種形狀，且沒有 `msg`。改成實況：

```
| GET | `/jobs/{id}/events` | — | SSE。兩種形狀共用同一條串流：
階段事件 `{event: "stage_start"|"stage_end"|"stage_fail", stage, sec?, code?, tail?, status, pct}`；
狀態事件 `{event: "state", status, pct, stage, error, deadline}` |
```

並在該節補一句：**階段失敗時，`tail` 帶子行程 stderr 的最後 20 行，經 `job.error` 送到前端顯示。** 這正是原 spec「錯誤處理」節要求的「顯示階段名稱與 stderr 末 20 行」的落實位置。

- [ ] **Step 2: 記錄 `<video>` 播放器的決策翻轉**

spec 的「非目標（YAGNI）」節列了「線上播放器」。實作有做，而且經審查後決定**保留**。把該項從非目標移除，並在該節下方加一段：

```
### 決策翻轉：內嵌播放器保留（2026-08-26）

原列為非目標，實作階段做了，審查後決定保留。理由：現場 Demo 的價值就在
「當場看到成品」，跳到下載再開播放器會打斷節奏。代價是 `GET /video`

不構成問題。若日後片長或檔案大幅成長，這個決定要重新評估。
