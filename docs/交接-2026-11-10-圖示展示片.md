## 改完之後怎麼重出

旁白不用重配（`story/audio/` 已有，句子沒改就別動 `story.py --dry`／`pages.py`，那會把實測時間蓋掉）。

```bash
ST=docs/experiments/2026-10-31-icon-demo/story; F=docs/experiments/2026-10-31-icon-demo/chalk; B=docs/experiments/2026-10-31-icon-demo/board
.venv/bin/python video_engine/explainer/storyboard.py $ST
python3 video_engine/explainer/sync_film.py $ST $F
python3 video_engine/explainer/chalk/tools/stamp.py $F
bash $F/tools/sfx.sh
node video_engine/explainer/chalk/screen_check.js $F
~/.local/share/pipx/venvs/webwright/bin/python video_engine/explainer/chalk/board_check.py $F
(cd $F && npx --yes hyperframes@0.8.81 check)
cmp $F/beats.js video_engine/explainer/chalk/starter/beats.js
.venv/bin/python video_engine/explainer/storyboard_to_scene.py $ST $B
.venv/bin/python video_engine/board/compile.py $B/scene.json $B/timeline.json --timing $B/timing.json --gaps $B/gaps.jsonl
.venv/bin/python video_engine/board/build.py $B/timeline.json $B/player --audio $ST/audio/narration.wav
~/.local/share/pipx/venvs/webwright/bin/python video_engine/board/check.py $B/player
```

渲染只在 Colab（記憶 `render-off-local`）：

1. 打包 `chalk/`、`board/player/`、`video_engine/board/export.py` 到 `videomaker_render/`，本機算 md5，Colab 等 md5 相同才解。
2. 黑板：`npx --yes hyperframes@0.8.81 render --quality draft --fps 30 --workers 10`（12 CPU 約 3 分半）。
3. 手帳：`python video_engine/board/export.py <player> out.mp4 --fps 30 --workers 10`（約 160 秒；要 `pip install playwright && playwright install chromium`）。
4. 兩支都 `ffmpeg -nostdin -vf scale=1280:-2 -crf 30 -preset veryfast -c:a aac -b:a 96k` 壓成審片版。
5. 一律用 `subprocess.Popen(..., start_new_session=True)` 起，另一格讀 log。
6. 這次踩到：`apt-get install` 卡在下載超過 3 分鐘 → 先 `apt-get update`，加 `-o Acquire::http::Timeout=20 -o Acquire::ForceIPv4=true`。
7. Colab 連上先印 `os.cpu_count()`；這次使用者開的是 L4＋大量 RAM（12 CPU）。**執行階段可能還開著，提醒使用者不用時關掉。**
