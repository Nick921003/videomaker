## 1. 調整背景與設計目標

使用者選定方案 B（階層漸變），但提出兩項色彩調整需求：
1. **畫布背景**：不喜歡原本 B 的黑/深冷深色背景（`#0b1329`），希望改為更耐讀的淺色畫布。
2. **根節點填色**：不喜歡原先強烈飽和的高彩電光藍（`#0284c7` -> `#2563eb` -> `#4338ca`），希望更典雅、更協調的新色調。
3. **保留結構**：保留卡片微漸變、隨深度尺寸與彩度遞減、卡片與背景界線分明等階層特性。

本調整將原先單一的方案 B 拆分為三種各具美學特質的淺色漸變色系頁籤供選擇：
- **B1 暖奶茶 (Warm Latte)**：陶土紅棕（Terracotta）根節點＋米奶茶淺色底＋暖赭、琥珀、可可、焙茶、蜜栗和諧分支。
- **B2 森林 (Forest Sage)**：深冷杉綠（Deep Spruce）根節點＋鼠尾草微綠淺色底＋翠柏、橄欖、青草、松針、山苔綠意分支。
- **B3 莫蘭迪 (Morandi Muted)**：玄青灰墨（Ink Slate）根節點＋暖霧灰淺色底＋乾燥玫瑰、灰綠、灰藍、煙燻紫、芥黃低彩度高級灰分支。

## 3. 端到端驗收數據 (Acceptance Facts)

### (a) 根節點文字 vs 根節點填色 WCAG 對比度 (≥ 4.5)

公式：`Contrast = (L1 + 0.05) / (L2 + 0.05)`，其中白字 `#ffffff` 之 `L1 = 1.0000`

- **B1 暖奶茶**：白字 (`#ffffff`) vs 陶土紅棕填色 (`#843822`, L: 0.0784)
  - 對比度：**8.17:1**（通過，遠高於 4.5:1，達 WCAG AAA 等級）
- **B2 森林**：白字 (`#ffffff`) vs 深冷杉綠填色 (`#16382b`, L: 0.0317)
  - 對比度：**12.85:1**（通過，達 WCAG AAA 等級）
- **B3 莫蘭迪**：白字 (`#ffffff`) vs 玄青灰墨填色 (`#2c353d`, L: 0.0342)
  - 對比度：**12.47:1**（通過，達 WCAG AAA 等級）

### (c) 畫布背景 vs 卡片填色相對亮度差與比例

- **B1 暖奶茶**：

  - 亮度比：`(1.0000 + 0.05) / (0.8011 + 0.05) =` **1.23:1**

  - 亮度比：`(1.0000 + 0.05) / (0.8472 + 0.05) =` **1.17:1**
  - 視覺效果：卡片表面明顯亮於淡鼠尾草綠底，輔以森林墨綠柔和陰影。
