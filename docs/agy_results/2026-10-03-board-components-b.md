# Resolved Ambiguities
- **`type` command behavior:** The spec mentions "新的一行出現「prompt＋空白」，args.text 逐字打出", but also `print` and `restart` say they end with a new empty prompt. I assumed `type` types on the *existing* empty prompt, and only creates the very first one if no prompt exists at the beginning of the session.
- **`walk` label positioning:** The spec says "標籤移到第 k 列". I made it interpolate its Y coordinate from the previous row (or from just below the title if it's the first row) to the target row k over the 35% animation duration.
- **`list` measure width:** The label for `walk` moves on the left. I added `labelW + 20` to the left padding of the cards so the layout accommodates it.
- **`list` measure height acts context:** The `player.js` `measure()` call only receives the `api`, not the filtered `acts`. So I used the global `window.BOARD_DATA.timeline.actions.filter(...)` to accurately include the dynamically appended rows into the height, preventing layout overlaps.
