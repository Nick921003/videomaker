在 VS Code 按右鍵選 **Run Code**（或按 `Ctrl+Alt+N`）執行下面這支程式：

```c
#include <stdio.h>

int main(void) {
	int n;
	printf("請輸入一個整數: ");
	scanf("%d", &n);
	printf("你輸入的是 %d\n", n);
	return 0;
}
```

結果下方的「輸出」面板只出現一行 `[Running] ...`，**「請輸入一個整數」沒有出現，程式也一直不結束**。

![輸出面板只有 [Running]，右上角紅色停止鍵亮著，程式卡住](截圖/printf/A_輸出面板_s1卡住.png)

程式沒寫錯。這是 **Code Runner 擴充套件的預設設定**造成的，改一個設定就好。

## 先改設定：讓程式在「終端機」裡跑

1. 上方選單 **檔案 → 喜好設定 → 設定**（或按 `Ctrl+,`）。
2. 最上面的搜尋框輸入 `run in terminal`。
3. 找到 **Code-runner: Run In Terminal**，把它**打勾**。
4. 回到程式，再按一次 `Ctrl+Alt+N`。

![搜尋 run in terminal，找到 Code-runner: Run In Terminal](截圖/printf/B1_設定_RunInTerminal未勾.png)

![打勾之後](截圖/printf/B2_設定_RunInTerminal已勾.png)

這次程式會在下方的「**終端機**」分頁執行：「請輸入一個整數」馬上出現，打數字按 Enter，就會印出結果。

![終端機分頁：提示字出現、可以輸入，每秒印一行的程式也正常](截圖/printf/C2_終端機_s1與s3正常.png)

> 如果終端機裡的中文變成亂碼，那是另一個問題，請看〈終端機的中文變亂碼〉（待寫）。

設定只要改一次，之後每支程式都會在終端機執行。

## 為什麼會這樣？

Code Runner 預設把程式的輸出送到「**輸出**」面板。這個面板有兩個特性：

- **它只能看，不能打字。** 程式執行到 `scanf` 時在等你輸入，可是你打的字送不進程式，所以程式永遠等下去。
- **字不會馬上出現。** `printf` 印的字會先放在程式裡的一個暫存區（叫做**緩衝區**），等裝滿了或程式結束時，才一次送出去。如果是送到終端機，字會立刻出現；但送到輸出面板時，就會一直放在緩衝區裡。

所以「請輸入一個整數」還在緩衝區裡，程式又卡在 `scanf` 等輸入，畫面上就什麼都沒有。

這跟有沒有換行無關。下面這支程式每秒印一行，每一行都有 `\n`：

```c
#include <stdio.h>
#include <windows.h>

int main(void) {
	for (int i = 1; i <= 5; i++) {
		printf("第 %d 秒\n", i);
		Sleep(1000);
	}
	return 0;
}
```

- 在**終端機**執行：每秒出現一行。
- 在**輸出面板**執行：前 5 秒什麼都沒有，程式結束時 5 行一次跳出來。

![輸出面板：5 行在程式結束時一次出現](截圖/printf/D_輸出面板_s3結束時一次出現.png)

## 網路上說加 `fflush(stdout)`，可以嗎？

`fflush(stdout)` 的意思是「現在就把緩衝區的字送出去」。先講結論：**在終端機執行時根本不需要它；在輸出面板執行時加了也沒用。**

**在終端機執行（改過設定之後）**：不用加。終端機會把字馬上顯示出來，上面那支沒有 `fflush` 的程式，提示字照樣出現、也能輸入。

**在輸出面板執行（沒改設定）**：在 `printf` 後面加上 `fflush`：

```c
printf("請輸入一個整數: ");
fflush(stdout);
scanf("%d", &n);
```

「請輸入一個整數」確實出現了，可是你一打字，VS Code 就跳出「**無法在唯讀編輯器中編輯**」，數字送不進程式，程式一樣卡住。

![加了 fflush，提示字出現了，但一打字 VS Code 就顯示「無法在唯讀編輯器中編輯」](截圖/printf/E_輸出面板_fflush後提示出現但唯讀.png)

這是因為輸出面板**本來就不能打字**，跟有沒有 `fflush` 無關。`fflush` 只解決了「看不到提示字」，解決不了「沒辦法輸入」：

| 在輸出面板執行 | 提示字 | 能不能輸入 |
|---|---|---|
| 沒有 `fflush` | 不出現（還在緩衝區） | 不能 |
| 有 `fflush` | 出現 | **還是不能** |

所以**程式只要用到 `scanf`，就要改設定**，加 `fflush` 沒有用。

## 卡住的程式要怎麼停？

按「輸出」面板右上角的**紅色方塊**，或按 `Ctrl+Alt+M`。

## 其他執行方式也會這樣嗎？

我們在 Windows（MSYS2 UCRT64 的 gcc、VS Code C/C++ 擴充套件）實際測過：

| 怎麼執行 | 會不會卡住 |
|---|---|
| Code Runner 的 Run Code（**預設**） | **會** |
| Code Runner 的 Run Code（勾了 Run In Terminal） | 不會 |
| 按 F5 除錯 | 不會 |
| 編輯器右上角 ▶ 的「Run C/C++ File」 | 不會 |
