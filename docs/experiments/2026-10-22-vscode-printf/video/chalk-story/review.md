# printf 沒出來？：骨架

- 症狀：按下去就卡住｜學生寫作業真的會遇到：按下執行，什麼都沒出來，程式停住
- 症狀：按下去就卡住｜程式照順序該先印提示再等輸入，實際上提示字沒出來、程式停住
- printf 為什麼沒出來｜Code Runner 預設在輸出面板跑；printf 的字會先放進緩衝區
- printf 為什麼沒出來｜在輸出面板，緩衝區的字要等程式結束才出來；改在終端機跑的話，字就會直接顯示
- 網路上的解法：加 fflush｜在 printf 後面加 fflush，把緩衝區的字推出來，提示字就出現了
- 可是 scanf 還是不行｜輸出面板只能看、不能打字，scanf 等不到你輸入，程式才會一直停著；這一點 fflush 幫不上忙
- 改在終端機跑｜實際操作：fflush 版能顯示但打不進去 → 先停掉 → 設定 Run In Terminal → 換回沒加 fflush 的版本，提示字直接出現，也能輸入
- 在終端機卡住怎麼停｜點一下終端機，再按 Ctrl + C

## 症狀：按下去就卡住

### 學生寫作業真的會遇到：按下執行，什麼都沒出來，程式停住（screen）

1. 這是一份作業：讓你輸入成績，再把成績印出來。
2. 程式寫好了，我們按右上角這個三角形，用 Code Runner 跑跑看。
3. 結果什麼都沒有出來，輸出面板只有一行 Running，程式就停在這裡。
4. 很多同學第一次用 VS Code 跑程式，都卡在這裡。

### 程式照順序該先印提示再等輸入，實際上提示字沒出來、程式停住（two-col）

5. 我們畫到黑板上看。照順序，程式應該先印出「請輸入成績」，再停下來等你打字。　〔先印提示 → 再等輸入〕
6. 可是右邊的輸出面板，提示字該出現的地方是空的，程式就一直停在這裡等。　〔提示字沒出來，程式停住〕

## printf 為什麼沒出來

### Code Runner 預設在輸出面板跑；printf 的字會先放進緩衝區（center）

7. 奇怪，程式明明有寫 printf，為什麼提示字沒有出來呢？　〔為什麼？〕
8. 先看程式是在哪裡跑。Code Runner 沒改設定的話，是在輸出面板跑。　〔預設：輸出面板〕
9. 然後，printf 要印的字不會直接到畫面上，會先放進一個暫存的地方，這叫緩衝區。　〔先進緩衝區〕

### 在輸出面板，緩衝區的字要等程式結束才出來；改在終端機跑的話，字就會直接顯示（two-col）

10. 在輸出面板跑的時候，緩衝區的字不會馬上印出來。　〔輸出面板：出不來〕
11. 要等整支程式跑完，這些字才會一起出來。　〔跑完才一起出來〕
12. 同樣這支程式，如果改在右邊的終端機跑，printf 一執行，字就會顯示出來。　〔終端機：直接顯示〕

## 網路上的解法：加 fflush

### 在 printf 後面加 fflush，把緩衝區的字推出來，提示字就出現了（two-col）

13. 那要怎麼辦呢？網路上有一個解法，在 printf 後面加一行 fflush。　〔加 fflush〕
14. fflush 會把緩衝區裡的字推出去，不用等程式結束。　〔推出去〕
15. 所以右邊這行提示字就出來了。　〔提示字出來了〕

## 可是 scanf 還是不行

### 輸出面板只能看、不能打字，scanf 等不到你輸入，程式才會一直停著；這一點 fflush 幫不上忙（two-col）

16. 可是程式還有下一行 scanf，要等你打數字。　〔scanf 要輸入〕
17. 問題是，輸出面板是唯讀的，只能看、不能打字。　〔只能看〕
18. 你從鍵盤打的數字送不進去，scanf 就一直等。　〔打不進去〕
19. 一開始程式停在那裡不動，就是因為 scanf 在等你輸入。　〔卡住的原因〕
20. 這件事 fflush 幫不上忙，要讓程式改在終端機跑。　〔改在終端機跑〕
21. 我們直接到電腦上做一次。　〔到電腦上做〕

## 改在終端機跑

### 實際操作：fflush 版能顯示但打不進去 → 先停掉 → 設定 Run In Terminal → 換回沒加 fflush 的版本，提示字直接出現，也能輸入（screen）

22. 先看加了 fflush 的這支，按三角形跑，提示字出來了。
23. 可是想在輸出面板打數字，下面就說這裡是唯讀的。
24. 唯讀就是只能看，所以數字打不進去。
25. 先別急著改設定，先按右上角這個紅色方塊，把卡住的程式停掉。
26. 為什麼要先停？因為程式卡著，會一直佔著執行檔。
27. 沒停掉的話，下次編譯會失敗，出現 Permission denied。
28. 停掉之後，我們讓 Code Runner 改到終端機跑。
29. 終端機就是下面這個可以打字的視窗。
30. 先點左下角的齒輪，選設定。
31. 在上面的搜尋框打 run in terminal。
32. 找到 Code Runner 的 Run In Terminal，把它打勾。
33. 這樣 Code Runner 以後都會在終端機跑。
34. 我們換回沒加 fflush 的那支，再跑一次。
35. 這次在終端機跑，提示字直接出來了。
36. 輸入 85，按 Enter，結果就出來了。

## 在終端機卡住怎麼停

### 點一下終端機，再按 Ctrl + C（two-col）

37. 那如果在終端機裡卡住，要怎麼停呢？　〔終端機卡住〕
38. 左邊這個終端機，程式一樣停在等輸入。　〔一樣在等輸入〕
39. 先點一下終端機，讓它接收你按的鍵。　〔先點一下〕
40. 再按右邊這兩個鍵，Ctrl 加 C，程式就停了。　〔Ctrl + C〕

## 結語

41. 所以記得，程式要輸入東西，就要在終端機跑。
