# C 語言迴圈基礎

## 學習目標
能用 for 與 while 寫出正確的重複動作，知道兩者各適合什麼場合，
並且避開初學者最常踩的兩個坑：差一錯誤與無窮迴圈。

## 痛點情境
要把一到一百加起來，用手寫一百行加法沒有人受得了。但改用迴圈之後，
新的問題來了：跑出來的答案常常差一點點。不是少加了最後一個數，
就是多加了一個不該加的。
更慘的是另一種情況，程式跑起來之後就停不下來，游標一直閃，
只能按 Ctrl 加 C 強制中斷。
這兩個坑都不是語法錯誤，編譯器不會幫你抓，只有結果會告訴你。

## 核心觀念
迴圈說穿了只有三件事：從哪裡開始、什麼時候繼續、每一輪怎麼變。
for 把這三件事寫在同一行，一眼就看得完，適合次數已經知道的情況。
while 把三件事拆開來寫，適合次數事先不知道的情況，
例如一直讀到檔案結束、或是等使用者輸入零才停。
中間那個是「繼續的條件」不是「結束的條件」，這個方向很多人會想反。

## 程式碼範例
```c
#include <stdio.h>

int main() {
    int n = 5, sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    printf("1 加到 %d 等於 %d\n", n, sum);
    return 0;
}
```

走讀時分四步：宣告變數並把累加器歸零、寫出迴圈的三個部分、
在主體裡累加、最後印出結果。
第四行的累加器一定要先設成零，不歸零的話裡面是垃圾值，加出來的東西沒有意義。
第五行括號裡用分號隔開的三段，依序是起始、繼續條件、每輪的變化。
第六行是迴圈主體，每一輪把當下的數字累加進去。

## 為什麼這裡是小於等於
因為題目要從一加到五，五本身要算進去，所以條件寫成小於等於。
但如果今天是走訪一個長度為五的陣列，索引是從零開始、到四結束，
那裡就要用小於而不是小於等於。
同一個符號在兩種情境下不一樣，這正是差一錯誤最常見的來源。

## 常見錯誤
用 while 的時候忘記在主體裡更新條件變數，條件就永遠成立，程式停不下來。
for 因為把更新寫在括號裡比較不容易漏，這也是次數已知時優先用 for 的理由。
