## 講解全文

### 變數與賦值

C 語言中的等號「=」不是數學上的相等，而是賦值運算。執行時會先讀取右側算式算出新值（舊分數加 5），接著把結果寫入左側變數 score 的記憶體空間中覆蓋舊值。

### 基本資料型別

int 型別只能存放整數，將帶有小數的數值指派給 int 時，C 語言會直接截斷小數部分，而非進行四捨五入。若需保留小數精度，應改用 float 或推薦的 double 型別。

### 格式符號與取址

scanf 需要取得變數在記憶體中的存放位址才能寫入資料，因此變數名前必須加「&」取址；且 scanf 對 float 與 double 格式要求不同，讀取 double 必須精確對應為 %lf。

### 型別影響運算

在 C 語言中，兩個整數相除會進行整數除法，小數會被捨棄只保留整數商 3；只有當運算對象包含浮點數（例如 7.0 / 2.0 或 7 / 2.0）時，才會執行浮點數除法得出 3.500000。
