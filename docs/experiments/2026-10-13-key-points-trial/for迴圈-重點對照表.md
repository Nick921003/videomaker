## 講解全文

### for結構與改寫

for 將計數控制的「初始化」、「繼續條件」與「更新」集中在括號內以分號隔開。進入迴圈時只執行一次初始化；每次執行本體前先檢查條件，成立才執行；本體結束後執行更新，再重新檢查條件。這與計數型 while 邏輯一致，但更集中易讀。

### 計數變數更新

i = i + 1、i += 1 與 i++ 在此效果相同，都是每次讓變數增加 1。若需要改變步進間隔（例如每次加 2 產生偶數），則可寫 i += 2。迴圈的執行次數是由起始值、繼續條件與更新步進量共同決定的。

### 迴圈次數與邊界

計數從 0 開始時，變數範圍是 0 到 N-1，條件需用 < N（共 N 次）；若從 1 開始，範圍是 1 到 N，條件需用 <= N（共 N 次）。若從 0 開始誤用 <= N 會多執行一次（N+1 次）；從 1 開始誤用 < N 則會少執行一次（N-1 次）。

### 讀取N筆資料實作

任務需求是「讀取一筆後立即印出一筆」，不需在記憶體中保留所有歷史數據。迴圈由計數變數 i 控制從 1 到 N 重複執行 N 次，每次讀入的新溫度值直接覆蓋同一個 double 變數並印出即可。

### 追蹤表與測試

條件判斷會執行 4 次。前 3 次條件成立（i 為 1、2、3）並執行本體與更新；第 4 次判斷時 i 增加至 4，條件不成立，程式直接離開迴圈，不再執行本體或更新。透過追蹤表與邊界測試（如 N=1）可驗證執行次數是否正確。
